Product Type Description

Add a searchable type description field on product forms, lists, and search views

Features

1 Dedicated product type description

Add a clean Type Description field directly under the product type selector. Use it for product families, classifications, usage categories, material grades, or internal catalog notes.

2 Search by description

The standard product search bar includes the type description field, so users can find products by values such as "checkpoint", "fabric grade", or any internal type label.

3 List and variant support

The field is available on product templates, optional in list views, and accessible from product variants through Odoo's native product inheritance.

4 Chatter tracking and translations

Changes to the type description can be tracked in chatter, and the field is translation-ready for multilingual product catalogs.

How to Use

Step 1: Install the module from Apps.

Step 2: Open Inventory / Products or Sales / Products.

Step 3: Fill Type Description on the product form.

Step 4: Search products using the same description value from the standard product search bar.
